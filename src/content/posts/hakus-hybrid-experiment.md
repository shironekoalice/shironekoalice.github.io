## 想验证什么

现代 LLM 的注意力窗口有限，窗口外的信息只能靠位置编码外推或者检索来补。有一类思路是在注意力之外加一条**持久状态**（persistent state）：一个随着序列更新、能被后续 token 读取的状态向量，相当于给模型一个容量很小的"工作记忆"。

这个想法听起来合理，但它容易被一种伪验证骗过：如果测试任务里答案其实还在窗口内，或者数据布局让最后一条事实恰好贴着查询，那么模型表现好，你根本分不清是状态起了作用还是注意力碰巧覆盖到了。

所以我做了一个小实验，目标不是证明这个架构好，而是**造一个能把"窗口外"变成物理事实的装置**，然后看状态到底能不能扛住。

## 实验设计：让注意力物理上看不见

核心是两条：

**1. banded causal mask，窗口固定 16。** 这不是软限制，是硬切断——当前 token 只能看到前 16 个 token，更远的直接被 mask 掉。

**2. 精确距离协议（v2）。** 任务是合成的 KV 回忆：文档里放 N 个 `(KEY, MEM, VAL)` 事实 + 噪声 + 查询，模型要输出查询 key 对应的 value。关键是布局：

```text
[事实1][事实2][事实3] [噪声 × d] [查询 KEY]
                                  ↑
                          恰好隔 d 个噪声 token
```

这样"事实到查询的距离"就精确受控了。d=8 时事实在窗口内，d=16 时刚好出窗，d≥24 完全不可见。

> 顺带说：我第一版协议（v1）把噪声插在事实前面，结果出现了"最后一条事实贴着查询"的伪影，读数虚高，整套结果废弃重跑。控制变量这件事，在合成任务里也一样要老老实实做。

## 模型和对照

五个变体，都用 CPU 训练 3000 步（主配置约 5.6M 参数，消融实验用 3.7M 配置）：

| 变体 | 说明 |
| --- | --- |
| `transformer` | 纯注意力，对照组 |
| `hybrid` | 注意力 + 8 个状态槽 + 可学习门 |
| `hybrid_nogate` | 同上，但门固定为 0.5 |
| `state_only` | 只有状态，没有注意力 |
| `rnn_attention` | RNN + 注意力的经典基线 |

状态层的结构大致是：路由（静态 slot key 决定写到哪个槽）→ 门（可学习 sigmoid 决定写多少）→ 候选（写什么），更新式 `S ← (1-a·g)S + a·g·c`。纯线性递推用 chunked cumprod 做了并行扫描（chunk=32、float64），所以训练不慢。

## 结果：能站住的部分

距离扫描（facts=3，每个点 n=192）：

| d | Transformer | Hybrid(gate) | Hybrid-NoGate | State-only |
| --- | --- | --- | --- | --- |
| 8（窗内） | 0.333 | **0.438** | 0.339 | 0.412 |
| 16（窗外） | 0.073 | **0.458** | 0.438 | 0.307 |
| 24 | 0.005 | **0.422** | 0.422 | 0.016 |
| 32 | 0.000 | 0.240 | 0.307 | 0.000 |
| 48 | 0.000 | 0.016 | 0.063 | 0.000 |
| 64+ | 0.000 | 0.000 | 0.000 | 0.000 |

三个我认为站得住的读数：

**第一，装置本身有效。** Transformer 在 d≥16 精确衰减到 0 —— banded mask 没有泄漏，这是这个实验能成立的前提。d=16 那个 0.073 就是"刚好出窗"的边界效应，符合预期。

**第二，d=24 处 0.422 vs 0.005，两次独立训练都复现了。** 门控版和固定门版都是 0.422，Transformer 是 0.005。这个 0.4 量级的差距远超种子方差，是状态在窗口外携带信息的因果级证据——不是相关性，是"把注意力物理切断后它依然能答对"。

**第三，state_only 在 d=24 崩了（0.016）。** 这个结果反而是好事：说明状态单独不够用，需要和注意力配合。如果一个纯状态模型就能打平，那说明测试太简单。

另外做了两个健全性检查：把状态 corruption 到 p=1.0 时，性能掉到盲猜水平——证明状态确实在被依赖，不是摆设；reset 状态后与 normal 有明显差距，方向支持状态承载跨段信息。

## 结果：不敢下结论的部分

这部分我想单独写，因为我觉得它比上面那三行数字更有价值。

**种子方差 ±0.06~0.09。** 这个项目的 `random` 没有固定种子，每次训练的数据集都不一样。实测跨 run 方差在这个量级，意味着**所有小于 0.1 的组间差异都不可靠**。上面那三个结论都在 0.3 以上，稳健；但下面这些就不行。

**"可学习门有价值"这条被自己否掉了。** 我原本假设门控会比固定权重好。实测：gated vs nogate 在 d=32 是 0.240 vs 0.307，固定门反而略优。而且门的指标是健康的（0.465±0.177），说明门确实在被使用——只是没转化成优势。当前规模下的结论只能是 Unsupported。

**d≥48 归零，不代表状态"做不到长程"。** 训练时的距离分布上限只有 ~24-40，d≥48 是分布外。这更像是外推失败而不是架构限制。真正的长程结论必须等距离课程训练（8~32 → 16~128 → 32~512 → 64~2048）。

**RNN+Attention 基线训练失败了**（acc≈0.008，接近随机）。所以"Hybrid 是不是 RNN 换皮"这个问题，这一轮根本没回答——对照失效了，不能拿它下任何结论。这条我一开始想含糊过去，后来还是在报告里明确标成"本轮无效"。

**Slot 数量消融没有出现容量单调增益。** N ∈ {1,2,4,16} 全部弱于主模型，那个 0.25 的平台更可能是训练预算和容量的联合限制，我没有拿到支持"容量假说"的清晰证据。

## 一句话总结

这个实验能说的：**在这个合成任务的这个规模下，持久状态确实能在注意力窗口外携带信息，差距是 0.4 量级，可复现。**

这个实验不能说的：门控有价值、状态能长程保持、这不是 RNN 换皮、这个结论能推广到语言建模。**5.6M 参数、单任务，所有结论严格限定在本协议内。**

## 下一步

报告里列了 v0.2 的决策清单，按优先级：

1. 距离课程训练，回答真正的长程问题
2. 固定 python/数据种子，每组 3 seeds，报告均值±std
3. 修 RNN+Attention 基线的学习率和初始化，补上"换皮"对照
4. 门机制重新设计或者直接删掉（当前证据不支持它的价值）
5. slot 路由从静态 key 升级为内容寻址
